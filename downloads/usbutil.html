Как правильно записывать игры для PS2 через USB Util

Обратите внимание: Файловая система FAT32 не поддерживает цельные файлы больше 4 ГБ. Если ваша игра весит меньше 4 ГБ, просто скопируйте её ISO-файл в папку DVD на флешке (USBUtil не нужен). Инструкция ниже нужна только для больших игр.

Способ 1. Нарезка игры (Для старых версий OPL и FAT32)

Этот способ разбивает игру на части, чтобы обойти лимит FAT32. Используйте его, если ваша приставка не видит другие форматы флешек.

  1. В левом верхнем углу программы нажмите Файл (File) → Создать игру из ISO (Create game from ISO) (или Ctrl + J).
  2. Слева выберите ISO-файл игры на ПК, а справа — корень вашей флешки.
  3. Напишите короткое имя игры (например, RE4) и нажмите Создать (Create).
  4. После завершения в корне флешки появятся файлы вида ul.01 и файл конфигурации ul.cfg. Игра готова к запуску.

Способ 2. Сборка обратно в ISO (Для игр до ~4.1 ГБ)

Если вы боитесь, что файл ul.cfg затрётся другими играми, игру можно собрать обратно в один файл, но только если её итоговый размер не превысит лимит FAT32 (4 ГБ).

  1. Выполните все шаги из Способа 1 (нарезка игры).
  2. В главном списке USBUtil нажмите на появившуюся игру правой кнопкой мыши.
  3. Выберите пункт Конвертировать в ISO (Convert to ISO).
  4. Укажите папку DVD на вашей флешке в качестве места сохранения и дождитесь окончания сборки.
  5. Удалите оставшиеся в корне флешки разделенные файлы (ul.01, ul.cfg), чтобы они не занимали место.
💡 Полезный совет для сайта: Если у вас свежая версия Open PS2 Loader (OPL), отформатируйте флешку в файловую систему exFAT. Она полностью поддерживает файлы больше 4 ГБ. Вы сможете просто кидать любые большие ISO-игры в папку DVD напрямую без использования USBUtil и без багов с файлом ul.cfg!
